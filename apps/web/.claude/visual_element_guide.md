# Visual Element Guide — Landing Page

**Purpose:** Visual field guide for identifying and discussing UI elements with the designer. Each element is defined once with a plain-language description, then mapped to where it appears.

**How to use this document:**
1. Look at a section of the app
2. Find the element in **Part A** (Master Element Catalog) by name or description
3. Check **Part B** (Page Location Map) to see everywhere that element appears

---

# PART A: Master Element Catalog

## Buttons

### 1. Outlined Pill Button
A capsule-shaped button with no fill — just a thin colored border (green for FM, red for FT) around a clear/transparent background. The text is dark green (FM) or dark red (FT). When you hover, the inside fills with a very faint tint of the brand color. All three instances on a given page say different things but look identical in shape and size.

### 2. Filled Primary Button
A solid capsule or rounded-rectangle button filled with the brand color (green FM / red FT) with white text inside. When you hover, the color darkens slightly and the button lifts up a tiny bit (1-2 pixels). Has a subtle colored glow/shadow underneath matching the brand color.

### 3. Inverted Filled Button
A solid white button with dark brand-colored text — the visual opposite of a Filled Primary Button. Used on dark background sections where a colored button wouldn't stand enough. When you hover, the white dims slightly to an off-white and the button lifts up a bit.

### 4. Circle CTA Button
A large round button (not capsule — actually circular) filled with the brand color, with white bold text stacked in two lines inside the circle. When you hover, the circle grows slightly (scales up ~5%) and the color darkens. Has a brand-colored glow shadow underneath.

### 5. Text Link
Plain text styled as a link — no background, no border around it. The text is small, italic, and has a thin line underneath it (like a subtle underline). The underline color is lighter/more muted than the text itself.

### 6. Capsule Badge
A small pill-shaped element (not a button you click for navigation) with a light background, thin border, and small text inside. Used to display information compactly, like a saved zip code. Has an icon to the left of the text.

---

## Icons

### 7. Icon-in-Circle (Large)
A medium-sized circle with a very faint brand-color fill, containing a darker brand-colored line icon in the center. The circle is noticeably larger than the icon inside it, giving it breathing room. Used for step illustrations.

### 8. Icon-in-Circle (Small)
A small white circle containing a small dark-colored line icon. Used inside colored bars/bands to make icons pop against the background.

### 9. Check Circle
A very small circle filled with the brand color, containing a tiny white checkmark. Used as a bullet point replacement in benefit/feature lists.

### 10. Feature Icon
A standalone line icon (no circle around it) in a muted color, sitting above a title and description. Larger than other icons on the page. The color is a warm tan/sand (FM) or dark red (FT).

### 11. Trust Dot
A tiny colored dot (brand color) used as a separator between short text phrases that sit in a horizontal row. About the size of a bullet point.

---

## Text Styles

### 12. Hero Headline (H1)
The largest text on the entire page. Bold, tight letter spacing, dark colored. One line of the headline is colored in a darker shade of the brand color to create emphasis. Only appears once on the page.

### 13. Section Heading (H2)
Large bold text used as the title of each major section of the page. Centered. Dark colored. Consistent size across all sections — noticeably smaller than the Hero Headline but still prominent.

### 14. Section Subtitle
Medium-sized text directly below a Section Heading. Lighter/softer color than the heading. Centered. Describes what the section is about. Slightly narrower than the heading (doesn't stretch as wide).

### 15. Body Paragraph
Standard reading text. Softer color than headings (olive-brown for FM, charcoal for FT). Relaxed line spacing for comfortable reading. Used for longer descriptive content.

### 16. Card Title
Bold-ish text inside a card element. Slightly larger than body text. Dark colored. Sits below an icon and above a card description.

### 17. Card Description
Smaller, lighter-colored text inside a card. Sits below the Card Title. Relaxed line spacing. Describes what the card's feature or step is about.

### 18. Stat Number
Very large, bold number text in the dark brand color. Sits between an icon (above) and a label (below). The number represents a count (like "12" or "5").

### 19. Stat Label
Very small, uppercase text with wide letter spacing. Sits directly below a Stat Number. Describes what the number counts (like "LISTINGS" or "VENDORS").

### 20. Trust Indicator Text
Small, muted-color text in a horizontal row, separated by Trust Dots. Phrases like "Verified Vendors" or "Secure Payments."

### 21. Fine Print
Very small text in a muted/gray color. Used for privacy notes, tips, and minor helper text. Often appears below input fields or buttons.

### 22. Inverted Heading
Same size and weight as a Section Heading, but white text on a dark background — used in inverted/dark sections.

### 23. Inverted Body Text
White or near-white text on a dark background. Used for benefit items and descriptions in dark sections. Slightly transparent white for subtler text.

### 24. Footer Link
Small text that changes color when you hover over it — starts as a muted warm tone and shifts to the brand color on hover. Sits in vertical lists organized by category.

### 25. Footer Section Title
Small, bold-ish text in a pale/light color. Used as the heading above a group of Footer Links. Stands out against the dark footer background but isn't as bright as white.

### 26. Copyright Text
Small, muted text centered at the very bottom of the page. Separated from the content above by a thin horizontal line.

## Cards & Containers

### 27. Step Card
A white rectangular card with a thin gray border, rounded corners, and a very subtle shadow. Contains an Icon-in-Circle (Large) at the top, a small numbered badge in the upper-right corner of the icon, a Card Title, and a Card Description. All content inside is centered.

### 28. Step Number Badge
A tiny circle filled with the brand color, containing a white number (1, 2, 3, or 4). Sits in the upper-right corner of the Icon-in-Circle inside a Step Card, slightly overlapping the edge of the icon circle.

### 29. Feature Card
A white (FM) or light gray (FT) rectangular card with rounded corners and a subtle shadow. Contains a Feature Icon at the top-left, a Card Title below it, and a Card Description below that. Content is left-aligned (not centered like Step Cards).

### 30. Phone Mockup
A visual illustration of a smartphone built entirely from styled boxes (not an image). Has a dark border frame, a notch at the top center, and inside shows a mock app screen with a search bar, a 2x2 grid of colored product placeholders, a cart button, and a bottom navigation bar with emoji icons. The phone sits to the right of descriptive text.

### 31. Feature Checklist
A vertical list of short phrases, each preceded by a small circle containing a checkmark character. The circles have a very faint brand-color tint. Used to list app capabilities.

---

## Sections & Backgrounds

### 32. Hero Section
The very first section at the top of the landing page. Has a gradient background that shifts from a pale warm tone at the top to a cream color at the bottom. Contains the Hero Headline, a subtitle, Outlined Pill Buttons, Trust Indicator Text, and a zip code entry area. Tallest section on the page — at least 650 pixels.

### 33. Stats Bar
A full-width horizontal band in a warm tan/sand color (desert sand). Contains three stats arranged side by side. Each stat has an Icon-in-Circle (Small) on top, a Stat Number in the middle, and a Stat Label at the bottom. Relatively compact height compared to other sections.

### 34. White Section
A section with a plain white background. Clean and spacious feeling. Used to let content breathe between colored sections.

### 35. Muted Section
A section with a very light warm gray background. Slightly darker than white but still light. Used for text-heavy content that doesn't need cards.

### 36. Warm Section
A section with a very pale yellow/sunshine background. Warmer than the Muted Section. Used for feature grids and app promotion content.

### 37. Dark Inverted Section
A section with a dark brand-colored background (dark green for FM, dark red for FT). All text inside is white or near-white. Creates dramatic visual contrast against the light sections above and below. Contains a benefits list and an Inverted Filled Button.

### 38. Gradient Section
A section where the background smoothly transitions from one color to another top-to-bottom. The Hero uses one gradient; the Final CTA section near the bottom uses a similar but lighter gradient to mirror/echo the Hero.

### 39. Footer Section
The darkest section on the entire page, at the very bottom. Uses the darkest color in the palette as its background. Contains link columns, brand description, and copyright. A thin horizontal line separates the links above from the copyright below.

---

## Form Elements

### 40. Zip Code Input
A capsule-shaped text input field with a thin gray border. When you click into it (focus), the border turns to the brand color and a faint colored glow appears around it. If there's an error, the border turns red. Sits next to or above a Filled Primary Button of matching width.

### 41. Location Display
When a zip code has already been saved, this replaces the Zip Code Input. Shows as a Capsule Badge with a map pin icon, the zip code, and a small "Change" text button to the right. Clicking "Change" switches back to the Zip Code Input view.

---

## Decorative Elements

### 42. Background Circle
A very large, very faint circle (barely visible — about 8% opacity of the brand color) positioned partially off-screen. Used as a subtle decorative element behind content. You might not notice it unless you look carefully at the background of certain sections.

# PART C: Vertical Differences

Most elements look the same between verticals but with different colors. Here are the specific differences beyond just green-vs-red:

| Element | Farmers Market (FM) | Food Trucks (FT) |
|---------|-------------------|-------------------|
| Hero Section background | Pale yellow gradient → cream | White gradient → light gray |
| Stats Bar background | Warm tan/sand | Light grey |
| Feature Card background | White cards on pale yellow section | Light gray cards on white section |
| Feature Icon color | Warm tan/sand | Dark red |
| Dark Inverted Section | Dark green background | Dark red background |
| Footer Section | Deep olive/forest background | Near-black background |
| All "brand color" elements | Green (#8BC34A) | Red (#ff5757) |
| Text color (headings) | Deep olive green | Near-black |
| Text color (body) | Olive brown | Charcoal gray |
| Button shadows | Green-tinted glow | Red-tinted glow |
| Overall warmth | Warm earth tones (creams, yellows, olives) | Neutral/cool tones (whites, grays, black + red accents) |
